# PETSCII-Pit & Self-Playing Demo

A C64 BASIC roguelike

[Road map](roadmap.md)

[Development log](devlog.md)

[PETSCIIPIT.BAS](petsciipit.bas) - C64 BASIC V2 source code

[PETSCIIPIT.PRG](petsciipit.prg) - BASIC executable

[PETSCIIPITDEMO.BAS](petsciipitdemo.bas) - Self-playing demo source code

[PETSCIIPITDEMO.PRG](petsciipitdemo.prg) - Self-playing demo BASIC executable

[MUSICPAL.PRG](musicpal.prg) / [MUSICNTSC.PRG](musicntsc.prg) - Music ("Dungeoneering" and "Assailing"), PAL and NTSC versions; the game, demo, and glyph showcase load the right one automatically, so both must be on the same disk

[GLYPHSHOWCASE.BAS](glyphshowcase.bas) - Custom characters demo source code

[GLYPHSHOWCASE.PRG](glyphshowcase.prg) - Custom characters demo BASIC executable
